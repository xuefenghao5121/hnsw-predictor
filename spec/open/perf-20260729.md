## SLA 违规分析

### 违规 1: Page Search QPS 下降 19%

**实测**: 1672 QPS (基线 2056, 下降 19%)
**根因分类**: C. 性能退化 -- 功能正确但 SLA 不达标

**分析**:
- recall 无提升 (95.70% -> 95.70%)，说明 pageSearchScan 未产生有效候选
- QPS 下降 0.11ms/query 来自 `unordered_set<uint32_t> page_considered` 的开销
- 可能原因: FINE_BUFFERED 模式下 page_cache 中的页数据未正确传递给 pageSearchScan
- Dynamic Width 无效果可能原因: EF=50 搜索仅 ~0.49ms，10 跳收敛阈值未触发搜索就结束了

### 违规 2: Dynamic Width 无效果

**实测**: 2025 QPS (基线 2056, 噪声范围)
**根因分类**: A. 代码缺陷 -- L2/L3 实现与 L1 契约不一致

**分析**:
- QPS 无变化说明收敛检测逻辑未实际触发
- EF=50 时搜索路径短，可能从未达到 DW_CONVERGE_HOP=10 的触发条件
