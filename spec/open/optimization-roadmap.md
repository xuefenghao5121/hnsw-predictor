## cgroup 诚实性修正 (2026-07-30, DEC-039)

> 之前所有性能数字在 30GB RAM 开发机上测量, page cache 白嫖了 8GB+ 数据。
> 真实受限内存下性能会显著降低。以下数字全部待重新验证。

## 全量放开场景优化路径 (2026-07-30, DEC-043~045)

> SLA-006 新增维度: 内存充裕时达到 hnswlib 70%+ QPS
> 当前差距: 4.6x (1T), 根因是两阶段搜索的固有开销

### 时间分解 (DiskHNSW 0.40ms/query)

```
PhaseA PQ 粗筛:     230μs (57%)   ← 图遍历 + PQ ADC 距离
Fine Rerank:        190μs (38%)   ← 100 候选 pread + L2
  pread 系统调用:     189μs        ← page cache 命中, 非磁盘
  L2 计算:             41μs
其他:                ~20μs (5%)

vs hnswlib 0.09ms:  90μs (100%)   ← 图遍历 + L2 一个 pass
```

### 优化优先级

| # | 优化 | 预期 | 机制 | 难度 | 条款 |
|---|------|------|------|------|------|
| 1 | PhaseA+Fine 融合 | -40% | 边遍历边精排, 消除重复 | 🔴 | DEC-045 |
| 2 | 批量 pread | -20% | 合并相邻页, 减少系统调用 | 🟡 | Q-006 |
| 3 | PQ SIMD dsub=4 | -15% | AVX2 LUT 充分利用 | 🟡 | DEC-036 |
| 4 | flat_vec_cache 增大 | -10% | 更多候选命中缓存 | 🟢 | - |
| **合计** | | **0.40→0.18ms** | | | |

### 目标

```
当前:  QPS 2492 (1T), 5693 (4T)   → hnswlib 21% (1T), 49% (4T)
优化后: QPS ~5500 (1T), ~10000 (4T) → hnswlib 48% (1T), 86% (4T)
```

> 注: 4T 场景差距天然较小, 因为 hnswlib 4 线程有锁竞争不 scale。
> DiskHNSW 的 pread 路径天然无锁, 多线程 scale 更好。
